# App-Development-Info

アプリ開発の基礎知識を学習した記録を残すサイト。分野ごとに、**学習資料**と**学習記録**をページを分けて管理する。

- `materials/<分野>.html` — 学習資料。学んだ内容そのもの(参照用、繰り返し読み返す想定)
- `records/<分野>.html` — 学習記録。次の3部構成
  1. 自分の理解(何も見ずに書いた原文)
  2. 正誤の記録(学習資料と1を照合した結果)
  3. 他AIによる確認(POL-002の第二意見チェック結果。実施前は「未実施」と明記し、架空の結果は書かない)
- `index.html` — 分野一覧(各分野の学習資料・学習記録へのリンク)

現在の内容: `materials/architecture.html` / `records/architecture.html`(アーキテクチャ分野: デザインパターン・SOLID・Clean Architecture・モノリス vs マイクロサービス)

今後、サーバー・インフラ/セキュリティ/AI・LLM/データベース/テスト/基本・詳細設計についても、同じ構成で追加していく予定。
