# App-Development-Info

アプリ開発の基礎知識を学習した記録を残すサイト。分野ごとに、次の4部構成でまとめる。

1. 学んだ内容(資料化した内容)
2. 自分の理解(何も見ずに書いた原文)
3. 正誤の記録(1と2を照合した結果)
4. 他AIによる確認(POL-002の第二意見チェック結果。実施前は「未実施」と明記し、架空の結果は書かない)

現在の内容: `index.html`(アーキテクチャ分野: デザインパターン・SOLID・Clean Architecture・モノリス vs マイクロサービス)

今後、サーバー・インフラ/セキュリティ/AI・LLM/データベース/テスト/基本・詳細設計についても、同じ4部構成で追加していく予定。

GitHub Pagesで公開: https://gurii-gabreh.github.io/App-Development-Info/
